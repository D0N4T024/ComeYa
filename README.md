# ComeYa
¡Bienvenidos a "ComeYa" - Una Aplicación Web de ecommerce enfocada en comida!

ComeYa busca transformar la experiencia de pedir comida a través de una plataforma digital intuitiva y eficiente. Nos enfocamos en la calidad, rapidez y comodidad para satisfacer las necesidades culinarias de nuestros usuarios.

Tecnologias usadas:

-El frontEnd de este proyecto esta construido en:
.NextJS (FrameWork de JavaScript)
.Css
.Implementeando librerias de componente: MaterialUI y ChakraUI

-El API de este proyeccto esta construido en:
.Swagger

-El backEnd de este proyeccto esta construido en:
.C# (.NET Core)
.Implementando: ElasticSearch y Stripe

-El motor de base de base de datos usado es:
.MySql
